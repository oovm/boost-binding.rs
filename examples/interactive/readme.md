# Interactive Example

This example demonstrates the interactive features of iTools, including the TUI (Text User Interface) components.

## Features

- Interactive progress bars
- Loading animations
- Interactive selection menus
- Command-line interface

## How to Run

```bash
# From the project root
cargo run --bin itools -- --help

# Run the interactive example
cargo run --bin itools dev
```

## Commands

- `init <name>` - Initialize a new iTools project
- `build` - Build the project
- `dev` - Start the development server (interactive)
- `check` - Check the project for issues

## TUI Components

### Progress Bar

Displays a progress bar for long-running tasks.

### Loading Animation

Shows a loading animation during processing.

### Selection Menu

Provides an interactive menu for users to make selections.
