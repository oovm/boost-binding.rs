# iTools 命令行工具教程

欢迎使用 iTools 命令行工具教程！本教程将帮助您快速上手 iTools，并掌握其核心功能。

## 关于 iTools

iTools 是一个命令行工具，主要提供命令解析、执行和 TUI（文本用户界面）功能。它使用 Rust 编程语言开发，提供良好的性能和用户体验。

### 核心功能

- **命令解析** - 支持命令行参数解析和执行
- **TUI 功能** - 提供进度条、交互式选择菜单、加载动画等
- **国际化支持** - 支持多语言界面
- **命令行构建器** - 提供流式接口构建命令行参数

### 支持的命令

- `init` - 初始化新项目
- `build` - 构建项目
- `dev` - 启动开发服务器
- `check` - 检查项目

### 使用方法

1. **初始化项目**：`itools init <项目名称>`
2. **构建项目**：`itools build`
3. **启动开发服务器**：`itools dev`
4. **检查项目**：`itools check`

iTools 命令行工具为开发者提供了简洁、高效的命令行交互体验！
