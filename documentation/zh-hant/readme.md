## 關於 iTools

iTools 是一個高性能、可擴展的互動式工具框架，專為開發者構建和管理開發工具而設計。它使用 Rust 程式語言開發，提供極致的性能和靈活的擴展能力。

### 核心特性

- ⚡ **高性能** - 基於 Rust 編譯時架構，提供極致的工具處理性能
- 🔌 **可擴展** - 靈活的插件系統，輕鬆集成各種高級功能
- 🌐 **多語言支持** - 統一 URL 路徑下實現多語言切換，無需維護不同路由
- 🎨 **主題定制** - 完整的主題系統，支持自定義組件和樣式
- 💚 **高性能原生實現** - 基於 Rust 全鏈路編譯器，提供極致性能
- 🏗️ **編譯時與運行時分離** - 清晰的架構設計，編譯時負責解析轉換，運行時專注交互體驗

### 支持的平台和語言

- **前端框架** - Vue.js、React、TypeScript
- **後端語言** - Rust、Node.js
- **構建工具** - Vite、Webpack

無論你使用什麼技術栈，iTools 都能為你提供出色的工具開發和管理解決方案！
