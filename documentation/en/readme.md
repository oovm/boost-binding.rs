## About iTools

iTools is a high-performance, extensible interactive tool framework designed specifically for developers to build and manage development tools. It is developed using the Rust programming language, providing extreme performance and flexible extension capabilities.

### Core Features

- ⚡ **High Performance** - Based on Rust compile-time architecture, providing extreme tool processing performance
- 🔌 **Extensible** - Flexible plugin system, easily integrate various advanced features
- 🌐 **Multi-language Support** - Implement multi-language switching under unified URL path, no need to maintain different routes
- 🎨 **Theme Customization** - Complete theme system, support custom components and styles
- 💚 **High Performance Native Implementation** - Based on Rust full-link compiler, providing extreme performance
- 🏗️ **Compile-time and Runtime Separation** - Clear architecture design, compile-time responsible for parsing and conversion, runtime focused on interactive experience

### Supported Platforms and Languages

- **Frontend Frameworks** - Vue.js, React, TypeScript
- **Backend Languages** - Rust, Node.js
- **Build Tools** - Vite, Webpack

No matter what technology stack you use, iTools can provide you with an excellent tool development and management solution!
